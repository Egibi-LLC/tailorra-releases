Anthropic Messages API client.

Two operations land here:

  • test_connection: a trivial round-trip used to verify a stored key.
  • extract_master: structured extraction of resume items using Claude’s Tool Use feature for guaranteed-shape JSON output.

Extract structured master-corpus items from resume text. Returns the raw JSON value the model produced (already validated as conforming to the requested schema by Anthropic’s tool-use mechanism).
generate_cover_letter
Compose a fresh cover letter for a tailored version. The model receives the master corpus (so it can ground claims in the candidate’s actual background) and the listing text (so it can match the language and call out the right experience). Optional intent lets the user nudge tone or angle (“emphasize culture fit”, “shorter”, “more formal”).
generate_cover_letter_system_prompt
System prompt for cover letter generation. Public so claude_cli can use the same prompt.
generate_field
Compose a fresh per-item field (experience summary, education notes, etc.) FROM SCRATCH given only the structured context the caller supplies. Distinct from refine_text, which polishes text the user already wrote, and from generate_personal_summary, which pulls the whole corpus. Per-kind system prompts bake in honesty constraints — the model writes only what the context supports.
generate_personal_summary
Compose a fresh personal-summary headline from the user’s master corpus rather than refining existing text. The model receives a JSON snapshot of every relevant section (experiences, education, skills, projects, certifications) plus optional user-direction; honesty constraints from the generate-prompt forbid invention.
generate_personal_summary_system_prompt
System prompt for the from-scratch personal-summary generator. Public so claude_cli can route through the same prompt.
generate_resume_style
Generate a CSS override block that styles the resume according to the user’s description. Returns CSS code only (no markdown fences). The CSS will be appended to the default Classic template’s CSS.
generate_resume_style_from_attachment
Generate a CSS override that mimics the visual style of an example resume the user uploaded. media_type is the file’s MIME type — supported values are image/png, image/jpeg, image/gif, image/webp, and application/pdf. PDFs use Anthropic’s document content block; images use the image block. additional_notes is appended to the prompt so users can call out specific aspects to keep or change.
polish_resume_html
Run a rendered resume HTML document through the model for a polish pass: tightening bullets, normalizing dates, and refining the embedded CSS. Returns a cleaned HTML document with the same overall structure as input. user_prompt is appended to the polish instructions when non-empty so callers can ask for specific tweaks (“tighten bullets”, “more whitespace”, “use a serif typeface”, etc.).
refine_text
Refine a single short field on the master corpus — an experience summary, an individual bullet, an education notes line, etc. The caller supplies the kind (which selects the system prompt with its honesty / scope constraints), the raw text, an optional structured context (employer, title, GPA, etc.), and an optional user direction (“emphasize leadership”). Returns the refined text only, no markdown / preamble / quotes.
suggest_resume_items
Given a job listing and the user’s master resume corpus, ask the model to select which corpus items should appear in the tailored resume. Returns the raw JSON the model produced via tool-use — arrays of master IDs grouped by kind, plus a short rationale. The frontend takes those IDs and toggles version_items in bulk.
system_prompt_for_generate_kind
Map the generate-kind discriminator to its system prompt. Public so claude_cli can route through the same prompts. Distinct from system_prompt_for_kind which serves the refine flow — generate prompts are more explicit about composing from scratch and respect only-what-the-context-supports rules harder, since there’s no raw text to anchor against.
system_prompt_for_kind
Map the kind discriminator to its system prompt. Public so claude_cli can route through the same prompts.
