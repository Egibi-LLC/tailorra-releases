pub fn sanitize_html_styles(html: &str) -> String
Expand description

Walk an HTML document and run sanitize on the contents of every <style> block. Used after AI-generated HTML polish to scrub the same hide-tricks (display:none, opacity:0, content: hacks) the standalone CSS sanitizer rejects, without needing a full HTML parser. Markup outside <style> blocks is copied through unchanged.
