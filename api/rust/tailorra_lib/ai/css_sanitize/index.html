Module css_sanitize 

Source
Expand description

Strip dangerous CSS declarations from AI-generated output.

The AI sometimes ignores prompt instructions and produces CSS that hides resume content (display:none, visibility:hidden, opacity:0, etc.) or hardcodes resume data into content: strings (e.g. body::before { content: "Jane Doe"; }). Both make the rendered resume unusable. Rather than trust the model, we walk the CSS declaration-by-declaration here and drop the offending ones before applying the styles.

This is a tiny brace/semicolon walker, not a full CSS parser — but it’s correct enough for the sub-200-line CSS blocks the AI produces. It handles quoted strings (single/double/escapes) and nested at-rules so that braces and semicolons inside string literals don’t break declaration boundaries.
