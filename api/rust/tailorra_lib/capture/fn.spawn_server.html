pub fn spawn_server(state: CaptureServerState, port: u16)
Expand description

Spawn the capture server on the Tauri-managed async runtime. Returns immediately; failures (port in use, etc.) are logged via tracing-style eprintln so the app doesn’t crash if capture can’t start. The settings UI can probe the port with a GET on /healthz to surface server health.

We use tauri::async_runtime::spawn instead of bare tokio::spawn because this is invoked from Tauri’s setup() callback — at that point the current thread is not inside a tokio runtime, so a direct tokio::spawn panics with “there is no reactor running”. Tauri’s async_runtime bridge defers to the underlying tokio runtime so the inner tokio I/O (TcpListener, axum::serve) still works.
