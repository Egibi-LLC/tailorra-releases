Tauri 2 entry point for the tailor desktop app.

Frontend (Angular) calls into Rust via tauri::invoke. AI provider calls, OS keychain reads, listing capture, resume parsing, and PDF export happen here. Database access runs in the WebView via tauri-plugin-sql (see db.service.ts); migrations are registered below, and the one Rust-side exception is the transactional workspace import in import.rs.

Modules§

ai
AI provider layer. Two providers are implemented: anthropic (the Messages API, key from the keychain) and claude_cli (the local Claude Code binary). Both cover the resume operations (extraction, suggestions, refinement, styling, polish); multi-modal style mimic from attachments is API-only. Operations are dispatched per-provider by the command layer in lib.rs; there is no shared trait yet. OpenAI, Gemini, and OpenAI-compatible remain planned variants only.
browser
Helpers for pointing the user’s browser at its extensions page during capture-extension setup.
capture

import
Transactional workspace import.
keys
Wrapper around the keyring crate for storing per-provider API keys in the OS keychain (Windows Credential Manager, macOS Keychain, Linux Secret Service). Keys never live on disk and never reach the WebView.
license
