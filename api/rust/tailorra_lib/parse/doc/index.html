Legacy Word .doc text extraction (Word 97-2003 binary format).

A .doc file is an OLE Compound Document with a WordDocument stream whose first 32 bytes form the File Information Block (FIB). The main body text lives between byte offsets fcMin (FIB+0x18) and fcMac (FIB+0x1C) within the same stream, encoded as either Windows-1252 or UTF-16-LE depending on whether the document was saved with extended characters.

We parse the simple case directly. For documents with a piece table (heavy revisions, complex structure) the fcMin/fcMac range may span gaps; we fall back to a heuristic that pulls printable ASCII runs out of the entire stream so the user still gets readable text.

See: “Microsoft Office Word 97-2007 Binary File Format Specification”.
