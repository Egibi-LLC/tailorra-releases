Module parse

Local file-format parsing for resume import.

Pure text extraction with no AI involved. Dispatches by file extension: PDF, DOCX, or plain text. The result is the raw text the user can copy into master sections by hand. AI-assisted structured extraction is a separate feature that operates on this same text.
