Class DesignerPageComponent

Resume Designer — a standalone workshop for exploring AI-generated resume styles independent of any tailored version. Previews render against built-in example data by default; the "Preview against" picker switches to the user's master corpus or a tailored version (and back) at any time. Saves outputs to the shared style_templates table so they're immediately usable from any tailored version.

State is intentionally ephemeral; navigating away discards variants, focus, and history. Templates are the persistence layer — anything the user wants to keep should be saved before leaving.
