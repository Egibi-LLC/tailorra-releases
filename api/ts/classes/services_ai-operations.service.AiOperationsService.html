Class AiOperationsService

Process-wide registry of in-flight and recently-completed AI operations. Lives at root scope so component navigation doesn't destroy operation state — the polish PDF the user just rendered is still in the service when they come back to the version editor.

Also emits toast notifications via ToastService when an operation completes (success or error) while the user is on a route other than the operation's source.
