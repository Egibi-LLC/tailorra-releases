applyExtractedToMaster

  • applyExtractedToMaster(extracted: ExtractedMaster): Promise<ApplyResult>

    Bulk-insert extracted items into the master tables. Items get source='ai_extracted' and reviewed=0 so they show up as needing review (the badge UI is a follow-up slice). Personal info is upserted only when no record exists yet — we never overwrite existing content.

    Each section also dedups against existing rows on a natural key so re-running extraction on the same resume doesn't multiply items. Match keys are case-insensitive and trimmed: experiences: (employer, title, start_date) education: (institution, degree, start_date) projects: (name) certifications: (name, issuer) other_items: (category, title) Skills rely on the DB-level UNIQUE constraint on (project_id, name).

    Parameters

    • extracted: ExtractedMaster

    Returns Promise<ApplyResult>

clearUnreviewedAIItems

  • clearUnreviewedAIItems(): Promise<number>

    Wipe every master row that was inserted by AI extraction and not yet reviewed by the user, for the active project. Items the user already accepted (reviewed=1) or entered manually (source!='ai_extracted') are preserved, including their parent experience: an unreviewed AI experience survives while any protected bullet still hangs off it. Returns the number of rows removed across all tables.

    Returns Promise<number>
