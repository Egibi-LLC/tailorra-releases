replaceSelections

  • replaceSelections(
        versionId: string,
        selections: Partial<Record<MasterKind, string[]>>,
    ): Promise<Partial<Record<MasterKind, string[]>>>

    Replace the version's selections wholesale. Drops every existing version_items row for the version and inserts the supplied set, preserving the order they appear in each kind's array (used by the AI suggestion flow). Cheaper than a 30-button toggle storm and gives an atomic "apply suggestions" semantic.

    Returns the selections that were in place before the replace so the caller can offer an undo. If a write fails partway, the previous selections are restored before the error propagates.

    Parameters

    • versionId: string
    • selections: Partial<Record<MasterKind, string[]>>

    Returns Promise<Partial<Record<MasterKind, string[]>>>

    Bulk-select every supplied master id under kind for the version (skipping any already selected). For experience kind, also cascades the per-experience bullet ids when supplied. Used by the section-level "Select all" toggle in the editor — one DB sweep + one reload instead of N reloads from per-row toggles.
