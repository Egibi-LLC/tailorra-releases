Class WizardService

Tracks the user's progress through initial setup and the first tailoring cycle. All step states are computed from the existing master/listing/version services — there's no separate wizard persistence to keep in sync.

The Getting Started page reads phases directly. The header chip reads criticalRemaining / allCriticalDone and is always rendered, so workspace switches never make it appear or disappear.

Guided wizard mode (off by default) flips on when the user clicks "Start guided setup" on the Getting Started page; while active a footer bar walks them through every step in phase order with Previous / Save & Next buttons. Pages that hold draft state (currently personal-info) register a save handler so Next can persist whatever the user has typed before moving on, even if the form isn't valid yet.
