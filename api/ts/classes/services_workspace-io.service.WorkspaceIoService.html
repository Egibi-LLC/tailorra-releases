Class WorkspaceIoService

Save / load / reset for the active workspace's working data.

Save serializes every project-scoped table (personal_info, experiences, education, …, job_listings, tailored_versions, version_items, style_templates) into a single JSON document. Reset wipes the same set of tables for the active project. Load wipes then restores from a saved JSON document.

Deliberately excluded:

  • version_snapshots are protected by BEFORE DELETE / BEFORE UPDATE triggers and represent real submission history. They survive reset and load. Save also skips them — restoring a snapshot would conflict with the trigger semantics.
  • The projects row itself: reset/load operate inside the active workspace, not on the workspace boundary. Workspace creation / deletion is a separate flow.
  • suggestions: a global autocomplete pool, not project-scoped.

Load runs through the Rust import_workspace command (src-tauri/src/import.rs) so wipe + restore happen in a single SQLite transaction: a failed import rolls back and the workspace is untouched. The command regenerates every row id and remaps child references, so the same backup can be loaded into several workspaces of one database without PRIMARY KEY collisions.
