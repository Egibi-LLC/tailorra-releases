Class WelcomePageComponent

First-run / no-workspace screen. Surfaces when the projects table is empty (whether it's a fresh install or the user just deleted every workspace). Two ways forward: create a new empty workspace, or pick a previously-saved backup file (.tailorra or .json) and restore it. Either path leaves the app with one active workspace and routes the user into Getting started; the AppComponent's redirect effect handles that navigation when projects() goes from empty to non-empty.
